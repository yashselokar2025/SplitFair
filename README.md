# SplitFair

A small tip calculator and bill splitter built from scratch in Cursor for **Global Hack Week: Hacktoberfest — Challenge 1: Build a Mini App with Cursor**.

Open `index.html` in a browser. Enter a bill, pick a tip percent (or type a custom one), set how many people are splitting, and the tip, total, and per-person amount update live. A dark mode toggle is saved in local storage.

## What Cursor helped create

Cursor scaffolded this single-page app (HTML, CSS, and JavaScript) from a blank folder, then helped wire live totals, chip-based tip presets, a people stepper, and a dark mode toggle so the calculator stays correct as inputs change.

## Run it

1. Open `index.html` in a browser, or visit the GitHub Pages site if enabled.
2. Try changing the bill, tip, and number of people — the totals should update immediately.
